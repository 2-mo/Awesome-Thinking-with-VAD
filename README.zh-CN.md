## 收录与核验

收录视频异常解释、推理、定位、理解评估，以及直接支撑这些目标的语义表征方法。当前核心目录不纳入 WACV、workshop、泛视频理解或静态图像缺陷检测。

- 正式发表信息优先于早期预印本信息；未确认录用时保留 arXiv，扩展或改名版本先核对关系再计数。
- 每篇记录一手来源和核验日期。“阅读关注”是编辑提示，不冒充复现实验确认的局限。
- 比较表各已填字段链接到依据；区分冻结主模型、提示优化与辅助模块训练。“待核验”不代表没有该能力。
- 数据登记不等于资源已开放下载；评测协议、论文关联和图片展示分别维护。

旧[会议笔记](archive/venues/)、[期刊笔记](archive/journals/README.md)与[广义数据集笔记](archive/dataset.md)保留为范围更广的历史资料，尚未全部复核。当前精选内容以上方索引为准；旧资料已归入 [archive/](archive/README.md)。
